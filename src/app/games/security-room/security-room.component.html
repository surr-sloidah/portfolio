The Security Room

Buddy: Chapter 2

An atmosphere-driven, PSX inspired horror game set after the events of the first Buddy game; The Security Room places you in the titular Security Room, awakening with no prior memories or knowledge, and no way to get out. Your only hope lies in the room's last functioning computer screen, and whatever tools the security system may hold, perhaps they can help you figure out the mystery behind the malevolent computer and what became of him.

Using a hybrid of the First Person and Camera/Surveillance styles of gameplay, your investigate skills, memory and time-management abilities will be tested as you attempt to escape from the room and discover the underlying mystery of this run-down facility, but be warned, you're not alone...
